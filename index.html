Features

Everything you need,
nothing you don't.

From Day 1 attendance to final grade computation — Instrux keeps your classroom running without the paper chase.

Class Management

Create and organize classes with DepEd subject selection, section names, and color-coded cover cards.

DepEd Ready

Student Roster

Manage your full student list with search, attendance summaries, and quick delete. Find any student in seconds.

Daily Attendance

Mark Present, Late, Absent, or Excused per student per date. Auto-saves on a single click.

DO 8 Compliant

Grade Computation

Weighted grading following DepEd Order No. 8, s. 2015. Automatic performance thresholds built in.

Content Repository

Upload and organize PDFs, docs, slides, images, videos, and links per class. Always within reach.

Calendar Planning

Month grid view with daily agenda and event categories — Meetings, Exams, Holidays, Reminders, Deadlines.

To-Do Flow

Quick-add tasks with priority and due date. Filter by Today, Upcoming, or Completed.

Teacher Profile

Manage your profile, update information, or delete your account with full data cascade cleanup.

Fully Offline

No account, no cloud, no subscription. Your data never leaves your computer.

DepEd Aligned

Grade computation follows DepEd Order No. 8, s. 2015 exactly — weighted components and thresholds.

Open Source

Built in the open with MVVM, 4-layer architecture, and 52 automated tests. Contribute on GitHub.

Getting Started

Up and running in minutes.

Clone, build, run. No cloud dependencies, no accounts required.

Prerequisites

.NET 10 SDK
Required runtime and build toolchain
SQL Server LocalDB
Included with Visual Studio or SQL Server Express
Windows 10 / 11
WPF is a Windows-only framework
Terminal
1# Clone the repository
2git clone https://github.com/Nepthys2006/Instrux.Core.App.git
3
4# Navigate to the project directory
5cd Instrux.Core.App
6
7# Build the solution
8dotnet build
9
10# Run the application
11dotnet run --project Instrux.Application
